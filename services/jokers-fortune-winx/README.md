## 历史回包解码检查（2026-10-16）

- 直接检查用户现有抓取，而非另开试玩抽样。旋转命令为 0，protobuf 省略 field 1，所以不能用 `08 00` 筛选；field 2 为下注消息，field 4 为 32 字节密钥交换公钥。
- 离线载入原版 WASM、保存的登录及旋转响应，解码返回错误 1307，不能据此判为无中奖。全部网络请求均在离线测试中拦截，没有向原版发送新下注。
- 原版 WASM 初始化调用 getRandomValues 生成 32 字节随机值。以固定测试值替换后，生成的请求 field 4 与该值派生的 X25519 公钥完全一致；与原始随机值、SHA256、Ed25519 公钥均不相同。因此请求中保留的是公钥，不是可直接用于还原历史响应的私钥。
- 当前抓取工具保存 HTTP 请求/响应及 WebSocket，但没有保存客户端解密后的 SpinResponse 或会话私钥。已保存加密回包尚不能确认 Scatter 是否中奖。此前 60 个独立公开试玩解码样本没有 Scatter，不代表用户这批抓取没有。
- 后续应在录制时保存客户端解密后的回合数据；若原录制页面仍存活，可先研究读取其现有会话数据，不能直接要求用户重复抓取。未停止或重启当前录制。
