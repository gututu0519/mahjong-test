启动 `python -m server.run --service-dir services/fortune-rabbit`，访问 `http://127.0.0.1:8101/`。

- 英文原版客户端，独立端口 8101、配置和 SQLite 钱包。

- 保留原版投注、自动、规则、赔付表及历史入口，不添加技术提示。
- 最新已保存录制含 640 条旋转、5 轮功能。末局中奖已补齐：总奖包含末奖，而 `fs.aw` 保留末局前累计；真实事务的重试、重启和历史汇总均不重复支付。177 项后端测试通过；原站中途恢复、功能历史及封顶回包仍待补抓。
