## 2026-10-17 完成范围

按已取得的原版帮助、赔付表和最新回包完成玩法及协议，不等待罕见样本。保留原版中英文、横竖屏、普通旋转、连消、两档 FeatureSpins、两种购买奖励、自动旋转、规则及历史入口。未添加技术说明浮层，未隐藏原版功能。

- 5×5 全盘同类 6 个起算奖，按原赔付表结算，消除后下落补牌。
- Wicked Grin 到底部后向上扩列；Epic 在底部触发其他列尚未落底的 Grin，保持未覆盖区域不变。Grinny 可产生普通或 Epic Grin。
- 多倍率按列从左到右、同列从上到下依次生效，作用于自身与相邻列上方金币；Coin Craze 同时乘已保存收集器。
- Stash 每列初值 ×1，先应用本次储藏倍率，再增加下一次倍率；`columnMult.m` 表示下一次值。
- Coin Craze 每列初值 1，倍率后再收金币；`totalBarAdd` 包含 `c/h/increase/total`，末尾独立 `finalWin` 事件汇总。
- 两种免费均支持追加同类 FS：落底后整列扩展，每个位置给 1–3 次，单列 5–15 次；`FsExpand` 与 `retrigger.p/s` 对齐。最多同时两列，不混合两种 FS，也不与 Grin 混合生成。
- Bonushunt 费用为基础下注 ×3，基础旋转的免费符号生成概率参数 ×5，免费期间回到常规参数；Grinny ×50，Stash 购买 ×80，Coin Craze 购买 ×200。概率参数提升不等于已校准原版实际五倍触发率。
- 整段奖金上限为基础下注 ×10000；包含尚未领取的收集器奖金，到达上限即结束，不继续剩余免费次数。
- 使用原字段 `buyBonus`；正奖金回合先扣费用并持久化待领结果，客户端 `win_presentation_complete` 确认后才派奖。相同请求重试返回原结果，重复确认不重复支付。刷新保留账号、下注档和序号，恢复待领回包。
