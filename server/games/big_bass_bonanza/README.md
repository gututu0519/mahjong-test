## 证据与已实现规则

脱敏样本位于 `server/tests/fixtures/big-bass-spins.json`，当前 430 条 doInit/doSpin/doCollect 响应，包括完整 20 次免费回合。导出只保留协议白名单，不保存远端令牌、Cookie、请求头。原始抓取继续保留在本机。

- 5 列 × 3 行，按行编码；10 条支付线来自 `desktop/game/game000.json` 的 LineInfo，赔付表和卷轴来自 doInit。
- 普通投注为 coin × 10。符号 1 为 Scatter，2 为渔夫 Wild，7 为鱼；Wild 代替除 Scatter 外的普通符号。
- 3/4/5 个 Scatter 分别给 10/15/20 次免费；3 个触发已由记录 641 验证，4/5 个来自规则面板。
- 免费渔夫收取全屏鱼值，每个渔夫分别收取，叠加当前批次倍率。记录 648 验证两个渔夫收鱼；记录 662 验证 2 倍收鱼。
- 渔夫累计达到 4/8/12 个后，在当前批次末尾追加 10 次，后续批次使用 2/3/10 倍。记录 652 达到第 4 个，直到记录 660 才返回 `fsmore=10`、`fsmax=20`、`accv=5;2~4`。
- 收鱼协议保留 `mo`、`mo_t`、`mo_tw`、`mo_tv`、`mo_c`；渔夫累计保留 `acci=0;1`、`accm=cp;cp~mp`、`accv`。
- 普通和免费中奖先累计，回合结束 doCollect 一次入账；重复请求幂等、回合内投注锁定、数据库恢复、账户隔离复用公共事务层。
