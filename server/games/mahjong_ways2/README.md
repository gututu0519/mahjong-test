# 麻将胡了 2：游戏模块

ID：`mahjong-ways2`；类别：转轴／连消（`slots`）；交互：请求逐步推进（`request_steps`）。
这是转轴游戏，不是真人麻将桌或牌局规则引擎。
规则实现在 `engine.py`，默认配置在 `config.json`，客户端字段转换在 `../../adapters/pg/`。
规则证据见仓库 `docs/mahjong-ways2-spin-interface.txt`；录制结果仅用于离线回归对照。

| 玩法 | 当前状态及依据 | 验证位置／尚缺验证 |
| --- | --- | --- |
| ways 赔付、百搭 | 已实现；已有样本对照 | `server/tests/test_engine.py` 样本算奖 |
| 连消补牌、金牌转百搭与下落 | 已实现；已有解析规则 | 金牌消除及 600 步不变量测试 |
| 普通及免费连消倍率 | 已实现 1/2/3/5、2/4/6/10 | 引擎测试；各倍率专项场景仍可补充 |
| 免费触发、消耗及续次 | 已实现基础流程；3/4 散布符有样本 | 免费授予、倒数及续次测试 |
| 5 散布符奖励 | 英文帮助明确写明每多一个散布符增加 2 次；此前仅 3/4 个有响应样本 | 规则文本已有依据，5 个的实际响应仍未验证 |
| 免费模式第 3 列全金牌 | 新导入的英文帮助明确：第 3 列除百搭、散布外均为金牌；当前引擎尚未实现该保证 | 待补规则实现及新盘、连消补牌专项测试 |
| 累计奖金和分阶段结算 | 已实现 | 引擎不变量与公共账本测试 |
| 大奖等级显示 | 已对接倍率阈值 | 尚未逐档验证客户端动画 |
| 购买奖励、特殊钱包 | 未实现，适配层明确拒绝 | 后续按规则证据接入 |
| 最高赢额封顶、罕见特殊方块 | 未实现 | 需要明确规则与边界样本 |
| 原版概率、RTP、转轴条带 | 未还原；目前为本地权重 | 不具备原版概率或 RTP 结论 |

通用会话、钱包、请求幂等、持久化和历史由平台负责，不在本游戏中重写。
新增特殊玩法时，需同时记录进入／退出状态、扣款时点、奖励归属、恢复方式、是否已验证及测试依据。
