## 状态口径

- **待实现**：当前代码尚未完成该功能，已有文字规则也不等于已经实现。
- **待本地验收**：实现或测试已存在，但尚未完成指定客户端流程、动画或运行环境的验证。
- **待原版证据**：已有规则实现及本地验证，仍缺原服务器回包逐项对照。本地生成、强制场景和后端模拟不能替代原版实录。
- **资源待补**：已确认文件、语言包或原版页面缺失；“资源待核查”则表示还不能确定缺少哪些文件。
- **暂不作为完成条件**：沿用用户已明确的范围约定，不重新变成阻塞项，也不标记为已实现。

本次逐一读取接入记录，检查资源索引对应的实际文件，并按索引现有字段校验大小和 SHA-256。表中的数量是**索引覆盖的唯一路径**，不是整款游戏的全部依赖；索引内无缺件不能证明所有未触发分支都已齐全。部分旧索引只有长度、没有哈希，已分别标明。

客户端验收结论沿用各款最近记录；本次没有重新操作全部 17 款的完整流程。最近一轮仓库后端 169 项测试通过，也不替代本页列出的界面和原版证据验证。
