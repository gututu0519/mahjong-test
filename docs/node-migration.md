# Node 全量迁移与切换

## 已实现范围

19 款游戏引擎及原协议、20 个独立服务配置（19 游戏 + game-api）、商户网关、模拟合作平台、平台/商户管理后台、RTP worker 均可运行于 Node。原大厅、客户端入口、语言、购买/免费/继续/收奖路径、规则、历史、WebSocket 通道与持久化布局保留。抓包、解包继续用 Python；旧后端保留用于对照和回退。

前端保持 `clients/`、`demo/` 和后台页面；Node 公共网关在 `node/gateway/`，独立服务在 `node/services/`，19 个引擎在 `node/migrated/server/games/`。美洲野牛商户计算仍使用 `node/games/buffalo-win/`，不连接商户钱包。

其余引擎与原协议采用离线 AST 生成 TypeScript，公共语义由 Node 兼容层实现。生成代码已纳入工作区，构建只用 TypeScript，运行只用 Node，不启动 Python 子进程。迁移转换和参考数据导出属于离线开发工具。生成代码的源文件摘要在 `node/migrated/sources.json`。

商户网关仍保留原产品范围：美洲野牛，外部游戏号 1。全部 19 款本机服务迁移与“19 款全部进入商户产品目录”是不同的工作；本次没有自动扩展商户授权或改变币值精度。六款 JILI/TaDa 服务原最小币值 10000，其余 100，各自隔离。

## 本机切换

1. 保存当前配置并备份 SQLite（包含一致的 WAL 状态）；停止待切换的 Python 服务。不要把源码回退当成数据回退。
2. 在 `node/` 执行 `npm ci`、`npm test`。保留全部现有 `clients/`、`demo/` 和 `services/*/config/`。
3. 原 `start-server.bat` 和每个服务的 `start.bat` 已默认启动 Node。单游戏仍用原端口及同目录 `data/games.sqlite3`。
4. 既有商户环境在原 `sandbox.json` 旁自动生成私有 `node.json`：继续指向原三库、密钥、商户和 8110/8111/8112；计算子服务使用 8113。原配置不覆盖。启动网关，再启动平台与后台。
5. 验证普通旋转、购买免费、完整功能回合、未结束回合恢复、重复请求、余额、历史、语言、规则和辅助通道。实际画面与生产数据副本验收仍需部署环境执行。

新增隔离环境与已有环境的启动方式、内部计算接口、辅助命令见 [Node 使用说明](../node/README.md)。本次开发验证使用临时数据和合成旧库，没有重置或改写用户当前私有数据库，也未切换正在运行的线上进程。

回退入口为同目录 `start-python.bat`；旧 Python 文件未删除。先停止 Node 和其计算子进程，再启动旧入口。生产回退必须检查未结算操作及双库一致性；不要覆盖新产生的交易。

## 构建与上线

运行包包括独立网关、美洲野牛计算、全部服务、后台前端和基础设施五个归档。`all-services` 只带客户端启动 HTML/本地适配脚本及私有协议模板；完整客户端大资源独立挂载或发布。资源布局和环境变量见包内 `ASSETS.md`。

美洲野牛继续绑定已有 S3 素材版本。其他游戏的 Node 代码可运行，不代表其 CDN 路由已经上线；要对每款补齐素材发布白名单和实际客户端验收。不得为了缩小包而删除原功能入口或公开私有 fixtures。

现有 `node/deploy/` 的生产配置和 systemd 模板面向美洲野牛商户拓扑：单实例网关、后台、计算服务和 RTP worker。其余独立游戏服务默认 loopback，用原配置可启动；不可直接当成具备商户授权的公网游戏服务发布。前端后台当前保持同源 Cookie/CSRF。

生产切换顺序：验证发布包与素材校验和 → 用真实数据库一致性副本验收 → 独立端口预启动 → 真实钱包与浏览器联调 → 切路由 → 检查账务及旧会话。数据库、密钥、日志放在发布目录外。构建和烟测不会执行部署或线上切流。

## 验证边界

自动化已覆盖 19 引擎固定种子参考、原六类协议响应、SQLite 余额/历史/状态恢复、签名、交易幂等与失败恢复、辅助平台、两类 WebSocket、20 服务入口和独立进程打包启动。详见 [验证记录](../node/VALIDATION.md)。

没有重新证明各游戏数学模型，也未重新执行百万级 RTP 校准。原版缺失证据和补抓操作仍以 [游戏验证与资源缺口](game-validation-and-resource-gaps.md) 及各游戏规则文档为准。真实商户、生产副本、完整视觉与 Linux/systemd 验收和线上切流尚未进行。
