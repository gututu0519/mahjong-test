## 已确认并实现

- 5×5 网格，按列存储。低符号 0–4 至少 7 个，高符号 5–9 至少 6 个，在任意位置计数；Wild=10 可同时支持多个符号奖。按获奖格并集消除，列内下落，再补牌。
- 固定基础 10 coins，普通下注 `1 1 10 <denom> 1`，GO Ultra 为 15 coins。赔付表见引擎配置，实际金额为 coins×denom；Wild 不凭空创建棋盘上不存在的普通符号奖。
- 每次付费旋转 Bob 前进 1–6 格，每 18 格跨一层，余数按基础面额分别持久化。跨层即时奖励为基础下注的 0.2/0.5/1/2/3/4/5/10 倍，不乘 GO Ultra 赔付倍率。
- 每个获奖符号组合充能 +1，单次旋转重新计数。3 点 Wild Rift 添加 1–4 个 Wild；6 点再加 1–4 个 Wild，并仅让下一次连消使用 2/3/4/5 倍。一次跨过两个阶段时添加 2–8 个 Wild。9 点在连消结束后进入宝藏室。
- GO Ultra 加价 50%，普通赔付常驻 2 倍；6 点阶段固定下一连消 5 倍，之后回到 2 倍；宝藏室初始及恢复生命为 4，普通模式为 3。
- 宝藏室只在空位落新符号。Coin=11，Key=12，Mimic/Chest=13。金币和宝箱锁定；新金币、钥匙、宝箱或开箱恢复生命；没有新事件则扣生命。金币值 10/20/30/40/50 基础 coins。宝箱初始倒计时 4/6/8/10/12，归零打开，钥匙可随机打开一个关闭的宝箱。钥匙不永久占位。箱奖为 100/200/500/1000/5000/10000/50000 基础 coins；未打开的箱子不计奖。
- 开箱动画完成后宝箱使用符号 14，位置继续锁定，不再次扣倒计时或重复计奖。多个钥匙分别选择尚未打开的箱子；同转的新箱子可被同转钥匙打开。倒计时先结算，然后处理新落点和钥匙，没有目标的钥匙也恢复生命并在下转消失。
- 全局最高赔付为基础下注 30000 倍，即 300000 coins；普通和 Ultra 都按未加价的基础下注计算。
- 满盘以 25 个锁定金币/宝箱为准，钥匙不计为锁定格。达到上限立即结束计奖，最后一笔只记剩余额度；同转的后续奖不再发出，已付金额、动画事件值和最终入账保持一致。封顶不再额外触发 Wild/倍率或新的宝藏室。
- 原版下注选择、GO Ultra、自动旋转、加速、音效、设置、规则、退出入口保留。没有增加技术说明浮层。没有额外添加原版不存在的购买免费旋转入口。

## 适配与结算

原版客户端本身支持 HTTP 和 WebSocket。原站选择 SignalR MessagePack WebSocket，本地选择原生 HTTP，保留 ASCII 命令格式；没有修改原版打包代码。资源及 API 地址通过启动配置映射为同源。

`103/101/104` 完成启动；`1` 扣一次下注；`2 4` 为动画确认；`2 6` 逐步继续；`4 0` 只结算一次正奖金。事务请求号幂等，重发不会重复扣款/派奖。刷新把未结算局的展示从保存结果重新播放，不重新抽奖、不再次前进 Bob。每标签页以请求包会话头选择钱包，不依赖另一标签页可能覆盖的 cookie。SQLite 和服务配置独立。

Bob 持久进度使用 `56 <数量> <面额 步数>... 18`，`113` 是会话过期命令。恢复数据在 `109` 前发送；原版重播会在画面再次扣下注，启动时的显示余额需相应还原，而事务钱包不变。宝藏室无新落点的连续旋转可打包，`3` 给出基础局金额与该次旋转前生命；`14` 结束奖励之后的继续请求才汇总基础局与宝藏室奖金，然后领取。

最新实录的开箱顺序：盘面 `1` 末尾标记为 3，普通更新组 `2 0 3 13 0 0` 的 `25` 仍携带关闭箱的倒计时；接着用 `2 0 0 12 1 0` 承载钥匙事件 `26`，或 `2 0 0 13 1 0` 承载倒计时事件 `27`。客户端完成开箱并继续后，再发送独立的 `11` 生命恢复组。下一转才在盘面和 `25` 中发送符号 14 及箱奖。多种开箱同转时按倒计时、钥匙顺序分别发送组；封顶/满盘时开箱后直接结束，不增加一次旋转。

平台推广模块保留：无活动账户返回空列表，SignalR `RefreshFeatureStates` 完成但不推送奖励。外部真钱账户、支付及推广活动不属于本地钱包实现，入口没有因缺失而删除。

原站说明中的 90 天未决局和 180 天收藏进度策略属于长期账户保留周期；当前独立试玩沿用平台的 24 小时会话，不把它宣称为等同于原站长期账户恢复。
