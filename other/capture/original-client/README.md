# 原始抓取转原版客户端

在 Windows 双击[选择抓取并转换.cmd](选择抓取并转换.cmd)，选择原始抓取文件夹。转换完成后会打开一个新结果目录，先看 `转换说明.txt`。

1. 选中单个采集批次，工具会读取 `manifest.json` 指向的响应正文；也支持目录里唯一一份内嵌响应正文的 HAR。
2. 选中包含多个批次的总目录，工具会让你选择批次。同一游戏、同一版本的补抓可以按住 Ctrl 多选。单批内有多个可识别的静态游戏页面时，还会让你选择目标入口。
3. 已匹配适配器的结果可以双击 `启动原版游戏.cmd`；独立静态游戏可以双击 `预览静态客户端.cmd`。缺资料或需要适配时，查看 `转换结果.json` 里的原因和已知差异。

默认每次在 `other/diagnostics/original-clients/` 下新建一个结果目录。工具读取原始抓取，核对后才写入新目录。玩家端使用原游戏的界面、脚本与素材。采集器的请求头、请求正文、平台会话和历史账单不会被拿来模拟游戏服务器。

## 哪些输入可以自动转换

| 输入 | 自动处理结果 |
| --- | --- |
| 已登记、同一版本的客户端 | 对所选采集的源文件逐一计算 SHA-256，再校验项目中相应的适配产物，写入本次结果的 `client/`。来源和产物的对应关系记录在 `来源索引.json`。启动器指定本次导出的客户端目录，并连接项目的本地试玩服务。 |
| 没有登记厂商、可独立运行的 HTML 游戏 | 从可识别游戏页面跟踪同源的 HTML、CSS、脚本及可静态解析的引用。原文件保留目录关系，PNG 按原位深及调色板转换为 Adam7 并复核像素。依赖闭合后生成可预览候选，真实业务交互仍需验收。 |
| 同名游戏出现不同字节、只有补抓素材、依赖缺响应正文 | 生成缺口报告。已有游戏列出缺失或摘要冲突的登记路径，可据此重新选择版本或补抓。 |
| 依赖尚未接入的服务器、WebSocket、动态加载、外部平台，或存在未适配图片及脚本 | 报告需要的适配。完整的网页源码也可能依赖服务器决定下一步结果。要支持这类游戏，需接入对应接口、规则和状态恢复，再从玩家入口实测。 |

接入网络游戏需要原版素材索引、源件与发布文件的校验和，以及能读取本次导出目录的本地服务。可用的游戏取决于当前检出的游戏实现和素材校验结果，缺少适配器资料会列出缺口。详见[适配器配置](adapters.json)和[抓取及按游戏归档说明](../response-capture/README.md)。

静态客户端中可验证的原始 JPEG 会在装有 Pillow 时转换成真实的 Adam7 PNG；预览服务会把旧图片地址指向新文件。色彩配置或旋转信息无法证明转换后与原图一致时，报告会列出原因。

## 命令行

工具使用 Python 3.10 以上。桌面入口优先使用本机已安装的 Codex Python，或使用系统 Python。多选窗口使用 Tk。静态预览使用 Python 的本机 HTTP 服务。已适配网络游戏的启动器另外需要可构建的原项目、Node.js 和该游戏的隔离 PostgreSQL 试玩配置。若配置未放在本项目约定的位置，启动前使用 `GTT_PG_CONFIG` 指向它。

在仓库根目录运行，可把输出写到自己选择的父目录。下面的路径替换为自己的实际位置。

```powershell
python other/capture/original-client/convert.py "D:\抓取\本次批次" --output "D:\转换结果"
python other/capture/original-client/convert.py "D:\抓取\首批" --add "D:\抓取\同版本补抓" --output "D:\转换结果"
python other/capture/original-client/convert.py "D:\抓取\游戏.har" --entry "/game/index.html" --json
```

命令行退出码为 `0` 时已生成启动器或静态预览，`2` 时已生成需要补充资料或适配的报告，`1` 时输入未读成功或操作出错。报告中的整批请求数含平台背景请求。响应正文条目数表示索引声明有正文；被选作客户端依赖的文件才执行内容校验。单个索引上限 512 MiB，单条响应上限 128 MiB。HAR 或单项文件超过限制时可按游戏分开抓取。

静态预览仅监听本机空闲端口，关闭预览窗口或在控制台按 Ctrl+C 即可结束。网络游戏的启动器单独登记启动时间、PID、端口及客户端目录，并在对应的 `run-*/ready.json` 中保存本机玩家入口。

## 自检

```powershell
python -m unittest discover -s other/capture/original-client -p "test_*.py" -v
```

有 Playwright 和 Chromium 时，自检还会从静态预览地址打开页面、实际点击并核对结果。游戏结算的逐局验收由各游戏的浏览器验证器执行。
