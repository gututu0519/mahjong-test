## 本地入口与兼容

`local-bootstrap.js` 在原始客户端脚本之前加载，完成以下操作：

- 将游戏业务请求指向当前本地服务，并添加本地游戏会话头。
- 按当前页面主机和端口补上原版资源参数 `or`，让共享模块和游戏目录具有绝对地址。试玩链接可省略该参数。
- 在图片、脚本、样式、XHR 与 fetch 请求发出前将已导入的资源地址改为本地路径。
- 将编码资源索引产生的旧 JPEG/WebP 请求路径转换成明确的新 PNG 路径；能够直接识别的文本引用也已替换。
- 保持原客户端的图片展示时序，不新增 `opacity: 0`、隐藏样式、等待 `load` 后才展示的逻辑或遮挡占位层。

新增入口脚本使用兼容 iOS 12 的语法，fetch 不存在时保留 XHR 路径。`local-frame-clock.js` 只在本地试玩或商户模式中，对可见 WebView 的帧回调提供定时回退；无对应原生接口时不替换，不改变隐藏页面的节流。

已通过源码 AST 检查：导入 JavaScript 与 HTML 内联脚本没有 BigInt 字面量，且解析无错误；没有 Import Map 或 `#entry`。已用隔离 JavaScript 上下文验证 `img.src`、`setAttribute`、XHR、fetch 的路径映射和本地会话注入。
