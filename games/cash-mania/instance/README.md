# Cash Mania 本地接入

平台游戏 ID：20。原厂游戏 ID：1682240。游戏代码：`cash-mania`。

本地客户端来自本次用户抓取的 Cash Mania 静态资源；接口改为连接本地服务，使用项目已有的会话、钱包、幂等结算与恢复机制。

## 已核实的协议

最新两批原始抓取共 413 条完整普通 Spin：3 列 × 3 行盘面，支付线位置为 `[1,4,7]`，下注为 `cs × ml × 10`。其中 22 条包含同局向下挪轴，28 条包含同局两侧重转。普通中奖规则、二进制往返及钱包变动关系已离线交叉核对。原始抓取包含线上会话信息，因此只保留脱敏后的协议证据。

## 实现范围

普通盘面由本地引擎根据种子和配置生成，按核实的规则计算结算金额。配置中的生成权重属于本地演示参数，不能用于推断原厂概率或原厂 RTP。

版本 0.2.0 可在已确定的普通中奖结果上生成向下挪轴或两侧重转。每局一次结算，选择频率和中间盘面分布属于本地模型。抓取的原版前端已在本机浏览器验证启动、普通旋转、含两侧重转的结算、赔付表、规则与历史页。免费旋转、购买及最大赢额终止仍缺完整交易证据。[客户端素材](../docs/客户端素材.md)

## 启动

在项目根目录执行 `npm start -- cash-mania`。独立试玩端口为 8103。统一商户试玩使用现有网关与模拟平台，计算服务端口为 8230。

客户端资源与图片转换记录见同级游戏的 `docs/客户端素材.md`。所有本地测试均使用虚拟钱包，不涉及线上玩家资金。
