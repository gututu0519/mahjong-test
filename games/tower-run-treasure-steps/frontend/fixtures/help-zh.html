Tower Run Treasure Steps

未完成的游戏

如果您的游戏回合被中断，所有游戏信息和已投注的赌注将被保存，直到您重新打开游戏。您可以从中断处继续未完成的回合。

除非您登录任何 Play'n GO 游戏，否则所有累积的收集物品和/或游戏进度将在 180 天后被清除。

机器故障将导致所有赔付和游戏无效。

信息

中奖图案组合必须至少包含 6 个图案。中奖图案可以出现在转轴上的任何位置，允许有空隙。

游戏规则

TOWER RUN TREASURE STEPS 是一个5列5行的下落式网格游戏。符号可以在屏幕上的任何位置支付。ROYAL 符号在有7个或更多匹配符号时支付；MONSTER 符号在有6个或更多匹配符号时支付。获胜符号会被移除，新符号会下落以填补网格。下落会持续进行，直到无法产生新的胜利。获胜组合和支付根据支付表进行。当有多个符号获胜时，所有胜利都会加到总胜利中。

WILD

TOWER RUN TREASURE STEPS 包含一个WILD符号。WILD符号可以替代其他支付符号，以帮助在级联过程中完成获胜。WILD符号像支付符号一样运作，并在新一轮旋转开始时从网格中消失。WILD符号可以在同一次旋转中贡献多个获胜组合。

BOB'S ASCENT

每次旋转时,角色(BOB)会沿着网格上方的路径移动1-6步,与旋转动画同步。每个MONSTER相距18步;如果BOB到达一个节点(MONSTER),则会触发遭遇序列并奖励一个INSTANT PRIZE,这是一个BONUS PRIZE。INSTANT PRIZE会在符号评估之前奖励。如果未到达,BOB的位置将保存至下一次旋转;此功能始终在下落/级联之前结算。每个新出现的MONSTER相距18步(固定值)。INSTANT PRIZE金额基于应用于基础投注的倍数。可能的倍数值为:x0.2;x0.5;x1;x2;x3;x4;x5或x10。BOB的进度会针对每个可用的投注等级单独存储。当您更改基础投注时,BOB的进度会随之改变,游戏会加载属于新选择投注的进度。如果您返回到之前的投注等级,游戏会恢复该特定投注之前保存的确切BOB进度。

WIN‑O‑METER OF DESTINY

WIN‑O‑METER OF DESTINY 位于网格上方，在旋转期间每次中奖获得 +1 充能。固定阈值 3/6/9 会触发递增的 POWERS（特色游戏）：WILD RIFT、DIMENSIONAL MULTIPLIER 和 TREASURE ROOM。阈值是线性的。WIN‑O‑METER OF DESTINY 在每次新旋转开始时重置。递进的 POWERS（3/6/9）为：

• WILD RIFT – 在 WIN‑O‑METER OF DESTINY 上获得3次胜利时，WILD RIFT 激活，并在当前胜利结算后、下一次连击检查之前，在空位置上放置1-4个随机的 WILD 符号。这有助于在同一次旋转中创造额外的连击胜利。

• DIMENSIONAL MULTIPLIER – 在 WIN‑O‑METER OF DESTINY 上获得6次胜利时，DIMENSIONAL MULTIPLIER 会为当前旋转激活一个GLOBAL MULTIPLIER，并在空位置掉落1–4个随机WILD符号；GLOBAL MULTIPLIER 适用于下一个级联序列中的所有网格胜利。之后，恢复正常规则。GLOBAL MULTIPLIER 的值为x2、x3、x4、x5，每次触发仅应用一个GLOBAL MULTIPLIER。如果跳过了之前的功能（WILD RIFT）——例如，2次初始胜利+4次级联胜利直接达到第2阶段——DIMENSIONAL MULTIPLIER 将在空位置掉落2–8个随机WILD符号并应用GLOBAL MULTIPLIER。

• TREASURE ROOM – 在获得9次胜利后，TREASURE ROOM (HOLD & SPIN)将在网格空闲时开始（所有连消完成，没有新的胜利形成）。

TREASURE ROOM

TREASURE ROOM 是一个 HOLD & SPIN（5×5 网格）。您从 3 次 LIVES 开始（3 次 RE-SPINS）；只有 COIN、MIMIC（CHESTS）和 KEY 符号可以落下。COINS 和 MIMICS 落下时附带 CASH PRIZES。COINS 在落下时立即奖励其 CASH PRIZE，MIMICS 在打开时奖励其 CASH PRIZE。新符号只能落在空白格子上；STICKY 符号永远不会移动或被覆盖；COINS 和 MIMICS 立即锁定在原位（STICKY）并保持在其落下位置；KEYS 不是 STICKY 且不会锁定。多个符号不能占据同一格子；不需要相邻；如果网格已满（STICKY 符号），则不会有更多符号落下。当 lives 达到 0 或网格已满（STICKY 符号）时，特色游戏结束。收集的 CASH PRIZES 总和即为最终奖励。当落下以下符号之一时：

• MIMIC — MIMIC 以关闭的 CHEST 形式落地，并显示倒计时，初始值可能为 4、6、8、10 或 12。倒计时在每次旋转开始时减少 1，当倒计时达到 0 时，MIMIC 将打开并显示 CASH PRIZE 数值，该数值将添加到总赢奖中。如果存在任何关闭的 MIMIC（CHEST），KEY 将随机打开其中一个。MIMICS 始终为 STICKY——无论它们是关闭还是打开状态，都会锁定在其落地位置，并且无法移动、替换或覆盖。落地一个 MIMIC 或打开一个，将使您的 LIVES（RE-SPINS）恢复到初始数量。CASH PRIZE 数额基于应用于基础投注的 MULTIPLIER。可能的 MULTIPLIER 数值为 x10、x20、x50、x100、x500、x1000 或 x5000。

• KEY — KEYS 没有直接价值。一个 KEY 会随机打开网格上已关闭的 MIMIC（CHEST）中的一个。当 KEY 落下时，您的 LIVES（重转 Spins）将完全恢复。KEYS 不是 STICKY；落下后，KEY 会消失——在打开一个 MIMIC 后立即消失。如果当 KEY 落下时没有已关闭的 MIMIC，该 KEY 仍会在下一次旋转时消失。

• COIN — COINS 落下时带有 CASH PRIZE 数值，并立即锁定（sticky）在其落下位置，直到特色游戏结束。每个 COIN 显示基于应用于基础投注的 MULTIPLIER 的 CASH PRIZE——可能的数值为 x1、x2、x3、x4 或 x5。当 COIN 落下时，您的 LIVES（RE-SPINS）将完全恢复。COINS 永远不会移动，永远不会覆盖其他已锁定的符号，并在收集前保持可见，直到特色游戏结束。在 TREASURE ROOM 结束时，所有 COINS 的数值将汇总在一起，并作为最终派彩的一部分直接添加到您的总奖金中。

使用投注按钮来选择注金。点击加号和减号按钮可对注金进行细微调整。点击“旋转”即可开始游戏。图案落地后，将根据赔付表由所显示的图案来确定中奖金额。然后，中奖组合将被消除，新的图案将落下以填补消除后的空位。

GO Ultra

GO Ultra 是一个切换按钮，可在基础游戏的空闲模式下开启或关闭。当特色游戏正在进行时，无法开启或关闭。如果开启，游戏中的特色游戏将获得增强效果，需额外支付总投注额的 50%。这 50% 的总投注额附加费不会影响与总投注额相乘的支付线赢奖或即时赢奖。增强效果如下：

• 1. 一个 GLOBAL MULTIPLIER x2 在基础游戏中永久激活。每个中奖组合都会翻倍，因为 GLOBAL MULTIPLIER x2 会自动应用于所有符号派彩。此增强功能始终激活，并影响基础游戏中的每次旋转、每次消除和每次符号中奖。GLOBAL MULTIPLIER x2 不会影响在 BOB'S ASCENT 的遭遇序列期间奖励的任何 INSTANT PRIZE。

• 2. 当在 WIN‑O‑METER OF DESTINY 上触发 DIMENSIONAL MULTIPLIER 时，永久的 x2 GLOBAL MULTIPLIER 切换为固定的 x5 GLOBAL MULTIPLIER。x5 GLOBAL MULTIPLIER 应用于下一个消除序列期间产生的所有中奖以及由此产生的中奖。这保证了此阶段的每次中奖都会乘以 x5。在 x5 GLOBAL MULTIPLIER 应用于该消除中奖后，multiplier 重置为持续的 GLOBAL MULTIPLIER x2。所有其他 DIMENSIONAL MULTIPLIER 行为保持不变：1-4 个随机 WILD 符号落在空白位置上，如果跳过了阶段 1（WILD RIFT），DIMENSIONAL MULTIPLIER 会在应用 x5 GLOBAL MULTIPLIER 之前落下 2-8 个随机 WILD 符号。WIN‑O‑METER OF DESTINY 在每次新旋转开始时正常重置。

• 3. 当 Treasure Room（Hold & Spin）开始时，该特色游戏现在以 4 个 LIVES（4 个 RE-SPINS）开始，而不是 3 个。所有其他行为保持不变。当 LIVES（RE-SPINS）降至 0 或网格被 STICKY 符号填满时，该特色游戏仍会结束，并且所有收集的 CASH PRIZES 的总和将作为最终赔付奖励。

只有当在 GO ULTRA 激活时的回合中触发特色游戏时，增强功能才会应用于该特色游戏。所有 CASH PRIZES 和特色游戏奖励均基于基础投注，即应用 GO ULTRA 之前的原始投注值。

仅当在 GO Ultra 激活期间的回合中触发特色游戏时，才会应用这些增强效果。

叫注

  • 修改您的注金 - 点击五个投注按钮中的任一个，选择其中一个注金或使用加减按钮一步步增加或减少注金。
  • 赔付表 - 打开赔付表。
  • 自动游戏 - 点击自动游戏按钮，即可启用/禁用自动游戏功能。在自动游戏模式下，将使用您的当前投注自动启动多轮连续的游戏回合。根据您的设置或当您的余额过低时，自动游戏模式将自动禁用。
  • 超级旋转 - 按住 SPACE 按钮不放，1.5秒后即可激活“超速旋转”模式。旋转将以极快的速度进行，但如果激活某个特色游戏，旋转速度就会变慢。
  • 开始 / 空格键 - 使用当前选中的注金开始游戏回合。点击“旋转”以开始。
  • 快速游戏 - 打开后可更快速地进行游戏。
  • 自动调整投注 - 在开始新的旋转时，如果余额太低，无法以当前注额等级开始旋转，则自动减少总注额。 所选的减少的总注额将是可能的最高注额，并且将低于初次启动自动旋转时所选的注额。 获得任何允许恢复初始注额的中奖后，注额只会减少，而不会恢复到初始金额。
  • GO Ultra 超级 - 一个切换按钮用于启用GO Ultra功能。开启时，额外增加50%的赌注到总赌注，以换取游戏中的增强功能。增强功能在游戏规则中有所指示。关闭GO Ultra将强制执行常规游戏模式。
