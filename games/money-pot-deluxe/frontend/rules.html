Caishen symbol

This symbol is the symbol of the Caishen, which will appear in all slots.

In the main game, it serves as both a collection symbol and a SCATTER symbol.

Collect symbols: If the Caishen symbol appears on a winning payline, it collects all Yuanbao bonuses on the screen and adds them to itself, without removing the Yuanbao bonuses.

SCATTER Symbol: If one Caishen symbol lands in the center position, you will enter the Golden Lock Respin. Before entering, the Caishen symbol collects all Yuanbao bonuses on the screen and carries them into the Golden Lock Respin. If there are no Yuanbao symbols to collect, the Caishen symbol will become a multiplier collection symbol once the Golden Lock Respin begins.

Golden Locking Respins: The Caishen symbol acts as a multiplier collection symbol.

Collect Multiplier Symbol: If a Caishen symbol appears on the screen, it collects all Yuanbao bonuses and adds them to itself, then applies an additional multiplier of x2, x3, x4, x5, x6, x7, x8, x9, x10, x11, x12, x13, x14, x15, x16, x17, x18, x19, or up to x20.

Mystery Symbol

This symbol is a mystery symbol that appears in the main game and the Golden Lock Respin.

Main Game: Appearing on the winning line will randomly award yuanbao symbol or Jackpot prizes.

Golden Lock Respin: If the Mystery Symbol appears during the Golden Lock Respin, it will randomly reveal a Yuanbao or Jackpot prize before the final settlement. If a Mystery Symbol appears in the main game and triggers the Golden Lock Respin, it carries over into the Golden Lock Respin.

Game Rules

This is a 3-row, 5-reel slot game with a fixed 6 paylines.

In the base game, paylines 1-3 must start from the leftmost reel, with 3 or more consecutive symbols from left to right. Paylines 4-6 must start from the rightmost reel, with 3 or more consecutive symbols from right to left. Symbols do not need to be the same.

Paylines:

Only the highest win per line is paid. When achieving a 5-symbol win, only one winning line is counted.

If there are multiple winning lines, all wins are summed.

Feature games use the same bet as the game of triggering spin.
