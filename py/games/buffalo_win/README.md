# Buffalo Win 规则引擎

玩法与概率边界见 [服务说明](../../../services/buffalo-win/README.md)，原始证据见 [规则分析](../../../docs/buffalo-win-rules-analysis.txt)。

`evaluate` 只评估传入的棋盘和扩展符号计数；`BuffaloWin.step` 生成每一步结果并返回整数分的扣款、派奖及新状态。HTTP、客户端协议、数据库均在引擎之外。生产运行不加载记录的旋转结果，也没有强制中奖接口。

已实现状态：普通起转、普通扩展、免费起转、免费扩展。普通起转扣款一次，扩展结束时统一派奖；免费起转和扩展均不扣款。免费倍率保留，普通新回合重置。回合内锁定投注和规则版本。

1.1.0 根据抓取的原版中英文说明补齐免费奖励与重触发、百搭列限制、堆叠大小范围及无限续列；新卷轴也可生成堆叠。免费内保留触发时的特殊符号字段和累计倍率。

测试包含 789 条脱敏离线样本重算、具体派奖例子、免费重触发与重复请求恢复、配置与投注约束以及 1,500 个生成步骤。样本匹配只验证已覆盖的确定性规则，不代表恢复了原厂 RNG、权重或理论 RTP；重触发尚无捕获响应可对照，按原版说明的奖励公式实现。

1.2.0 新增 `buy_free=true` 购买动作，按最新原版 `fb=2` 和 75 倍基础投注扣款，经触发续列进入 10 次免费。购买动作不写入后续锁定投注，续列／免费不重复扣款；进行中的回合拒绝新购买。已有已知 1.1.0 自然回合可继续，未知规则版本继续拒绝跨版本推进。完整 25 步购买证据、随机生成分布与验证边界见服务说明的“购买免费旋转”。
